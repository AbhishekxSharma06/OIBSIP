## 2. Functional Walkthrough Sequence
1. **Pizza Builder**: Show the 4-step wizard (Base, Sauce, Cheese, Veggies) and demonstrate real-time visual pizza rendering and dynamic price calculation.
2. **Checkout**: Add to Cart, review item breakdown, enter delivery address, and trigger the Razorpay test payment modal.
3. **Live Order Tracking**: Show order confirmed, transition to real-time tracker, and demonstrate the active progress stepper.
4. **Admin Operations**: Sign in with `admin@pizzalab.com`, view the order in the operations queue, advance status to *In Kitchen* -> *Sent to Delivery*, show the customer tracking view updating in real time, and demonstrate the low-stock inventory restock (+10).
