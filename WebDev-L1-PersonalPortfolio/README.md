# WebDev-L1-PersonalPortfolio — Digital Resume

> **OIBSIP Track**: Web Development & Designing  
> **Level**: 1 | **Task**: 2  
> **Tech Stack**: HTML5, CSS3, Vanilla JavaScript (Zero bloated frameworks)

---

## 📌 Project Overview
A personal portfolio and digital resume showcasing engineering skills, featured web applications, background, and contact details. Adheres strictly to the **OIBSIP Shared UI System** with 8-point spacing, accessible high contrast, and smooth anchor navigation.

---

## 🎯 Acceptance Criteria & Checklist
- [x] **Hero Section**: Full Name (`Abhishek Sharma`), role title (`Full Stack Engineer`), avatar SVG representation, and live availability badge.
- [x] **About Me**: 2-3 structured paragraphs detailing development philosophy and engineering standards.
- [x] **Skills Visual Grid**: Categorized into *Frontend Engineering*, *Backend & APIs*, and *Workflow & Tooling* using interactive skill badges.
- [x] **Project Cards**: 3 featured project cards (`PizzaLab Full-Stack`, `AuthVault System`, `TaskFlow Pro`) with descriptions, tech tags, and links to source/demo.
- [x] **Contact Section**: Reachable email, LinkedIn, and GitHub links plus interactive validated contact form.
- [x] **Smooth-Scroll Navigation**: Accessible `#about`, `#skills`, `#projects`, `#contact` scroll links with automatic active scroll spy and mobile menu drawer.

---

## 🚀 How to Run Locally
Open `WebDev-L1-PersonalPortfolio/index.html` in your browser, or serve locally:
```bash
python -m http.server 3000
```
Visit `http://localhost:3000/WebDev-L1-PersonalPortfolio/`.
