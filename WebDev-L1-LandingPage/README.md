> **OIBSIP Track**: Web Development & Designing  
> **Level**: 1 | **Task**: 1

## 📌 Project Overview
Nova is a modern, responsive developer landing page built for high conversion and architectural clarity. Engineered with semantic HTML5 elements, CSS custom property tokens, and mobile-first responsive breakpoints conforming strictly to the **OIBSIP Shared UI System**.

---

## 🎯 Acceptance Criteria & Checklist
- [x] **Sticky Navigation**: Stays accessible upon scrolling, contains brand logo, nav links (`#features`, `#metrics`, `#workflow`, `#pricing`), and primary CTA button.
- [x] **Hero Section**: Prominent display heading (`Build your next big thing`), clear value subheadline, version release badge, and call-to-action button.
- [x] **Interactive Code Mockup**: High-contrast terminal showing build telemetry and edge deployment confirmation.
- [x] **Distinct Content Sections**:
  1. *Core Capabilities Grid*: 3 cards highlighting edge delivery, CI/CD pipelines, and SOC2 compliance.
  2. *Live Telemetry Metrics*: 4-stat KPI row with SLA uptime, latency, and throughput numbers.
  3. *Workflow Step breakdown*: 3-stage visual path (`git push` to global production) with live pipeline indicator.
  4. *Pricing Matrix*: 3 transparent tiers (Developer, Pro Team with featured badge, Enterprise).
- [x] **Footer**: Multi-column links (Product, Resources, Connect) and copyright notice.
- [x] **Accessibility & Responsiveness**:
  - Global `box-sizing: border-box`.
  - Accessible `:focus-visible` ring across interactive elements.
  - Zero horizontal overflow down to 320px screen width.

## 🚀 How to Run Locally
1. Clone or open the repository folder.
2. Open `WebDev-L1-LandingPage/index.html` directly in any web browser, or launch a local preview using Python:
   ```bash
   python -m http.server 3000
   ```
3. Visit `http://localhost:3000/WebDev-L1-LandingPage/` in your browser.
